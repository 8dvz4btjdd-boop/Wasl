| tl | Tagalog | ltr | Inter | translated from en | **needs native review** |

## Rules

- No user-facing string outside `messages/*.json`. Write en first, then ar; the others are translated from en.
- Every file has the same keys. ICU placeholders and plural branches are kept exactly.
- The language menu names each language in its own script (`LocaleSwitcher.locales`, identical in every file).
- User-written text renders with `dir="auto"`, so it follows its own direction inside either layout.

## Open points for native reviewers

- **ur**: `Card.follow_up` uses a masculine verb ("چاہتا ہوں"); a neutral wording is needed since askers can be anyone. `Demo.continues` is feminine because the demo's second dāʿī is Sara. "AI" is kept in Latin script.
- **id**: `Topics.ethics` is "Akhlak" (more natural for an Islamic topic than "Etika"); `Presence.offline` is "Luring".
- **tl**: names follow the personal markers si/kay/ni (`Card.preferredTitle`, `Inbox.transferTitle`); "Palayaw" for pseudonym; technical words (routing, fallback, latency) are kept as loanwords.
- All three: check that `{time}` phrases ("Awaiting your reply {time}", "Usually available {time}") read naturally with the formatted values.
